Configuración

💾 Los cambios se guardan automáticamente al salir de cada celda. Las nuevas aplicaciones se dan de alta con el botón «＋ Añadir aplicación», que abre un modal de confirmación. Para apps del IES, escribe solo la ruta (p. ej. mmo); el prefijo https://iesvilladiego.github.io/ se añade automáticamente. Para una URL externa, pega la dirección completa empezando por https:// y la celda cambiará sola al modo externo. 👁 La casilla Act. controla si la app se muestra en su perfil: desmárcala para desactivarla (queda atenuada, NO se borra) y el filtro «🚫 Desactivadas» las lista todas para volver a activarlas.

Exporta todo o parte de la configuración a PDF o Excel (.xlsx). Las librerías se cargan bajo demanda al pulsar el botón (no afectan al rendimiento inicial). Si marcas «Aplicaciones», podrás elegir en el panel inferior exactamente cuáles exportar: marcando casillas individuales, pulsando los chips de perfil (un clic marca todo el grupo, otro clic lo desmarca) o filtrando la lista por perfil. Con un filtro o búsqueda activa, «Todas», «Ninguna» y los chips se aplican únicamente a las aplicaciones visibles.

⚠️ Seguridad: Al exportar "Administradores", sus contraseñas serán visibles en el archivo. Protege el archivo exportado.

Añade aplicaciones masivamente desde un archivo Excel (.xlsx) exportado previamente desde este portal (hoja «Aplicaciones»). Se omitirán automáticamente los duplicados: se considera duplicada cualquier aplicación cuyo nombre o URL coincida con una ya existente en la base de datos o que esté repetida dentro del propio archivo. También se aceptan archivos antiguos cuya columna de perfil se llame «Administrativa» (se importará como «Recursos»).

⚠️ Importante: Solo se importan los datos de aplicaciones (nombre, descripción, URL y perfiles). Las contraseñas de perfiles y administradores que pudiera contener el archivo NO se importan.
